# 🚀 Advanced C# Practice Projects

This repository contains several advanced C# console applications focused on Object-Oriented Programming, delegates, events, custom collections, iterators, exception handling, and software design patterns.

---

## 📂 Projects

### ⚙️ Event-Driven Job Scheduler

A console-based job scheduling system that executes queued jobs through delegated executors while publishing lifecycle events and collecting execution statistics.

**Key Concepts**

* Delegates
* Events & EventHandler<T>
* Custom Queue Implementation
* IEnumerable / IEnumerator
* Dynamic Arrays
* Event-Driven Architecture
* Exception Handling
* Monitoring & Logging Services

---

### 🛡️ Mini Rule Engine

A configurable validation engine that applies dynamic business rules to different entity types using fail-fast and collect-all validation strategies.

**Key Concepts**

* Delegates
* Interfaces
* Custom Exceptions
* Rule Engine Architecture
* Fail-Fast Validation
* Collect-All Validation
* Extension Methods
* Dynamic Array Management
