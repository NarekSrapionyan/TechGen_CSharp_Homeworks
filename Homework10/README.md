# 📚 Library Catalogue

A console application built with **C#**, **Entity Framework Core**, and **PostgreSQL** that demonstrates a complete database read/write workflow.

The project covers database creation, data seeding, LINQ querying, entity tracking, updates, deletes, aggregation, and PostgreSQL-specific behavior.

## Tech Stack

- **C# / .NET 8**
- **Entity Framework Core 8**
- **PostgreSQL 16**
- **Npgsql**
- **Docker**

## ✨ Features

- Database and schema creation with EF Core
- Initial data seeding
- LINQ-based querying
- Filtering and sorting
- Data projection with `Select`
- Pagination with `Skip` and `Take`
- Aggregation with `Any`, `Count`, and `Sum`
- Case-insensitive search with PostgreSQL `ILIKE`
- Entity state and change tracking
- Update and delete operations
- Server-side grouping with `GroupBy`
- Generated SQL logging
- PostgreSQL UTC timestamp handling
- Database DDL generation

## 🐘 Database

The application uses PostgreSQL running in Docker.

Example setup:

```bash
docker run -d \
  --name library-postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=library \
  -p 5432:5432 \
  postgres:16
```

The connection string can be configured in `LibraryContext.cs`.

> For real applications, database credentials should be stored in configuration or a secret store rather than directly in source code.

## Entity Configuration

The `Book` entity is configured through EF Core Fluent API.

| Property | Configuration |
|---|---|
| `BookId` | Primary key, generated by database |
| `Title` | Required, max length 200 |
| `Author` | Required, max length 120 |
| `Price` | Precision `10,2` |
| `AddedAt` | UTC timestamp |
| `Author` | Indexed |

EF Core generates the PostgreSQL schema automatically from this model.

## 🔎 Query Examples

The project uses LINQ to build queries that are translated to SQL by EF Core.

```csharp
var books = db.Books
    .Where(b => b.Year > 2005)
    .OrderBy(b => b.Title)
    .ToList();
```

Other demonstrated operations include:

```text
Where
OrderBy
OrderByDescending
Select
First
Find
Any
Count
Sum
Skip
Take
GroupBy
```

PostgreSQL-specific case-insensitive search is implemented with:

```csharp
EF.Functions.ILike(b.Author, "%martin%")
```

## Change Tracking

Entities loaded through the context are tracked by EF Core.

Updating an existing book only requires changing its property and saving the context:

```csharp
book.IsRead = true;
db.SaveChanges();
```

EF Core detects the modified property and generates the required `UPDATE` statement.

The project also demonstrates `AsNoTracking()` for read-only queries.

## 🚀 Getting Started

### Requirements

Make sure the following are installed:

- .NET 8 SDK
- Docker
- PostgreSQL Docker image

### Restore dependencies

```bash
dotnet restore
```

### Build

```bash
dotnet build
```

### Run

```bash
dotnet run
```

On startup, the application recreates the database schema, inserts the initial dataset, and executes the implemented database operations.
